# Local Kanban

在线地址：https://mineoclock.github.io/work-kanban  

一个将看板数据直接保存到本地 JSON 文件的轻量看板工具。  
可创建多个状态列，todo卡片在列间移动。

## 数据持久化

首次使用时，请点击“选择看板文件”打开已有的 `.json` 文件，或点击“新建看板文件”创建文件。之后的新增、修改、排序和删除操作都会自动保存到该文件。

## 操作方式

- 在 Todo 输入框中输入内容，按 `Enter` 或点击别处确认。
- 双击状态列名称或 Todo 内容，可进行修改；按 `Enter` 或点击别处保存。
- 拖动状态列左侧的拖动手柄，可调整状态列顺序。
- 拖动 Todo 到其他状态列，可改变其所属状态。
- 右键菜单中选择“删除”可删除 Todo 或状态列。
- 点击“新状态列”可添加状态列。
